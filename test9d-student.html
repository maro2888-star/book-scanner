スマホde選書システム

実証テスト9-G 生徒側

Test9-G専用の新しい3件を、AES-GCMで暗号化して受付へ送信します。
受付には暗号鍵・氏名・ISBN・出版社・書名・価格の平文を送りません。

① 選書会用暗号鍵を読み込む

Test9-D～Fで使用したものと同じ選書会用AES-GCM鍵を使います。 この実証ページでは、鍵をブラウザのWeb Cryptoへ読み込んだ後、 入力欄の文字列を消します。

② Test9-G専用3件を送信

各ボタンは1回だけ押します。
A・B・Cで毎回ランダムな12byte IVを生成します。

Test9-G送信データ

A：TEST9G_生徒A / 9784912345732 / TEST9G_秘密出版社A / TEST9G_秘密の本A / 4111円
B：TEST9G_生徒B / 9784912345749 / TEST9G_秘密出版社B / TEST9G_秘密の本B / 4222円
C：TEST9G_生徒C / 9784912345756 / TEST9G_秘密出版社C / TEST9G_秘密の本C / 4333円
